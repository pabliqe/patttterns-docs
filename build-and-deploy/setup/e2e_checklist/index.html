E2E Deploy Checklist

Legacy doc. Initial Netlify setup checklist from early project bootstrap.
Current guides: Deployment · Content refresh & CI · publish directory is out, not .next.

✅ Pre-Deploy (Local)

Section titled “✅ Pre-Deploy (Local)”
  • Build exitoso - npm run build completado sin errores
  • Variables de entorno - .env.local configurado correctamente
  • Git inicializado - Repositorio listo
  • Archivos de configuración
    • netlify.toml creado
    • .gitignore verificado
    • DEPLOY.md con instrucciones

📋 Comandos Rápidos

Section titled “📋 Comandos Rápidos”

1. Preparar y Commit

Section titled “1. Preparar y Commit”

2. Deploy a Netlify via GitHub Sync ⭐

Section titled “2. Deploy a Netlify via GitHub Sync ⭐”

Verificar Deploy:

  • Ve a: https://app.netlify.com/sites/TU-SITIO/deploys
  • Status debe ser: “Published”
  • Build logs deben mostrar: “Site is live”

🧪 Pruebas E2E Post-Deploy

Section titled “🧪 Pruebas E2E Post-Deploy”

Test 1: Homepage

Section titled “Test 1: Homepage”

Manual Check:

  • Logo/título visible
  • Bases de datos inline renderizadas
  • Imágenes de cover cargan
  • Iconos visibles
  • Estilos aplicados correctamente

Test 2: Navegación a Página Individual

Section titled “Test 2: Navegación a Página Individual”

Manual Check:

  • Click en cualquier patrón
  • Página individual carga
  • Contenido de Notion renderizado
  • Botón “Back” funciona
  • URL amigable (slug correcto)

Test 3: Imágenes de Notion

Section titled “Test 3: Imágenes de Notion”

Manual Check:

  • Cover images cargan desde Notion CDN
  • Imágenes inline visibles
  • No hay errores 403 en console

Test 4: Performance

Section titled “Test 4: Performance”

Targets:

  • Performance: > 80
  • Accessibility: > 90
  • Best Practices: > 90
  • SEO: > 90

Test 5: Mobile Responsiveness

Section titled “Test 5: Mobile Responsiveness”

Manual Check (Chrome DevTools):

  • iPhone SE (375x667)
  • iPad (768x1024)
  • Desktop (1920x1080)

Test 6: Metadata & SEO

Section titled “Test 6: Metadata & SEO”

Expected:

  • <title> presente
  • <meta name="description"> presente
  • Open Graph tags presentes
  • Twitter card tags presentes

Test 7: Todas las Páginas Generadas

Section titled “Test 7: Todas las Páginas Generadas”

Test 8: Error Handling

Section titled “Test 8: Error Handling”

Manual Check:

  • Página inexistente → 404 correcto
  • Error de Notion API → mensaje amigable

Problema: Imágenes no cargan

Section titled “Problema: Imágenes no cargan”

Debug:

  1. Check browser console (F12)
  2. Verificar next.config.ts remotePatterns
  3. Verificar que Notion integration tenga permisos

Problema: Página en blanco

Section titled “Problema: Página en blanco”

Debug:

  1. Check browser console
  2. Verificar NOTION_HOMEPAGE_ID en Netlify
  3. Verificar que la página de Notion esté compartida

📊 Métricas Esperadas

Section titled “📊 Métricas Esperadas”

Build

Section titled “Build”
  • Tiempo: 2-4 minutos
  • Páginas generadas: ~21
  • Tamaño bundle: < 5MB

Runtime

Section titled “Runtime”
  • TTFB: < 600ms
  • FCP: < 1.8s
  • LCP: < 2.5s
